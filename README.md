# UI/UX Design Portfolio

A personal portfolio website built with React to present my UI/UX and product design work.

The portfolio focuses on visual design, UX thinking, information architecture, design systems, and the presentation of case studies.

## Projects

### Promptly AI

A conceptual SaaS landing page for an AI-assisted content platform.

**Focus**
- SaaS landing page design
- Visual hierarchy
- Product presentation
- Conversion-oriented layout
- Responsive design concept

**Tools**
- Figma

[View Promptly AI case study in Figma](https://www.figma.com/design/Ok5c4n6HTynuxw9zeKTe3e/Promptly-AI?node-id=91-319&t=tazqdTQj0n3IcKWw-1)

### BeautyCRM

A desktop CRM interface concept for beauty businesses, focused on customer retention, customer risk segmentation, customer profiles, and campaign analytics.

**Focus**
- B2B product design
- Information architecture
- Complex data-heavy interfaces
- Design systems
- UX workflows
- Desktop-first interface design

**Tools**
- Figma

[View BeautyCRM case study in Figma](https://www.figma.com/design/062byklUZsOkvseGyoW2Tb/Beauty-CRM?node-id=0-1&t=sEdwGy4PJiASyDgs-1)

> Promptly AI and BeautyCRM are conceptual UI/UX design projects created in Figma. They are presented here as design concepts and case studies, not as implemented products.

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The portfolio will then be available at the local development URL shown in the terminal.

## Design Approach

The portfolio is intentionally minimal and editorial. The visual system uses:

- large typography
- generous whitespace
- restrained color palettes
- reusable components
- consistent spacing
- structured case-study presentation
- selected screenshots instead of full-page image dumps

Each project has its own visual identity while following the same presentation principles.
